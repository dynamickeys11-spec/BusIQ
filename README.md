# BUSIQ

BUSIQ is an AI-native Business Intelligence Operating System (BIOS).

## Product direction

BUSIQ is built around a continuous intelligence loop:

**observe → learn → connect → analyse → predict → recommend → prepare**

The product is organised around five experiences:

- Workspace
- Discover
- Build
- Library
- Account

The Business Intelligence Engine (BIE) is the reasoning layer. It prepares decisions; the human remains the decision-maker.

## Build rule

This repository is the authoritative implementation surface for BUSIQ. Product authority lives in the constitution and supporting architecture documents. Implementation must not introduce dashboard-first UI, model/provider selectors, or business capabilities as standalone modules.

## Current phase

**Phase 0 — Foundation**

The first implementation establishes the product constitution, architecture constraints, design tokens, typography, accessibility baseline, and a demonstrable foundation surface.
