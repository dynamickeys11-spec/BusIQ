# BUSIQ Design System v1.0

## Tokens

- Midnight: #0B1020
- Indigo: #4F46E5
- Background: #F8FAFC
- Surface: #FFFFFF
- Success: #22C55E
- Warning: #F59E0B
- Error: #EF4444

## Typography

- Headings: Sora
- Body and numerals: Manrope
- Metrics, tables, scores and financial surfaces use tabular/lining numerals.

## Geometry

- 8pt spacing system
- Radii: 8 / 12 / 16 / 24px
- Exactly three elevation levels

## Interaction

Motion must teach rather than decorate.

Accessibility is a standing requirement: keyboard operation, visible focus, semantic structure, screen-reader support, 44px targets, meaning not conveyed by colour alone, dynamic viewport sizing, and reduced-motion support.
