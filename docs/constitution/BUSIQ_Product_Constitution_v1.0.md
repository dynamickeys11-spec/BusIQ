# BUSIQ Product Constitution v1.0

## Purpose

BUSIQ is an AI-native Business Intelligence Operating System (BIOS). Its purpose is to reduce the cognitive load of business decision-making by continuously resolving business context and preparing useful decisions, explanations and actions.

## Core principles

### 1. Business Intelligence Engine

The Business Intelligence Engine (BIE) is BUSIQ's reasoning layer. It continuously:

**observe → learn → connect → analyse → predict → recommend → prepare**

BIE is not a visible product surface.

### 2. Intent before tools

The user expresses an outcome. BUSIQ resolves the capabilities and information required to support that outcome. Users should not have to assemble a tool chain before asking for business help.

### 3. Five experiences

BUSIQ has five experiences:

- Workspace
- Discover
- Build
- Library
- Account

These are experiences, not disconnected application modules.

### 4. Human authority

BUSIQ prepares decisions. The user decides.

### 5. Glass-box intelligence

Significant intelligence outputs must make it possible to understand:

- what it means
- why it matters
- evidence
- confidence
- assumptions
- risks
- alternatives
- methodology
- trace

Progressive disclosure is the default: Summary → Explanation → Evidence → Methodology → Full Trace.

### 6. Continuous operating environment

BUSIQ should feel like one continuous operating environment rather than a collection of applications. Context determines intelligence, actions and workflows.

### 7. Calm and timeless design

The design system prioritises clarity, restraint, legibility, accessibility and low cognitive load.

## Non-goals

BUSIQ is not a dashboard, generic assistant, module collection, model selector, KPI tile grid, or bespoke insight-markup surface.

## Authority

This document is product authority. Lower-level implementation must not redefine these decisions.
